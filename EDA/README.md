# Movies Dataset - Exploratory Data Analysis

**Project Description**
Performed Exploratory Data Analysis (EDA) on a Movies dataset to uncover trends, patterns, and insights related to genres, ratings, popularity, revenue, and other key movie attributes using Python data analysis and visualization libraries.

**Key Learnings**
- Handling incorrect data types during analysis.
- Understanding why correlation should only be performed on numeric columns.
- Identifying and resolving common mistakes encountered during EDA.
- Using visualization techniques to discover meaningful patterns and insights.
